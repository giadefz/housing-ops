# Scraping posture: personal use, pacing, no circumvention

Status: accepted.

housing-ops is a personal-use tool. Bundled providers pace themselves (≥3s
between requests, low page ceilings), never circumvent bot protection, and
report a walled source as degraded health instead of routing around it; the
user is responsible for complying with each portal's terms, stated in the
README and license notes.

A portal that walls itself off is a signal to switch to a local adapter, not
an obstacle to defeat. If terms forbid it, we ship no bundled provider for
that source at all — the machinery is the product.
